# ClozDesign 关键词与页面承接地图

2026 年 10 月 7 日。下面 80 个候选词分为 16 个意图组，结合本次 Google、Bing 查询和 AI 引用、当前产品功能及竞品公开入口重新整理。目标是增加可被当前产品满足的非品牌需求，而不是按词数批量建页。

**优先执行已有流量的 Dress、Polo，以及尚缺 sitemap 覆盖的 on-model 入口。** T-shirt 泛词继续优化，但新页面优先围绕真实款型、操作任务和输出结果。关键词没有未经验证的搜索量或难度分数；未获得本站曝光的词属于待验证候选。

证据等级：A 为本站当前查询、点击或 AI 引用；B 为本次竞品官方页面和搜索结果确认的意图；C 为现有能力可满足的待验证需求。每组内不同词可能证据不同，组内存在 A 不代表每一个长尾都已获得曝光。优先级综合证据、产品匹配和实施成本，不是精确预测。

## 每类页面只承担一个主要任务

| 页面类型 | 主要职责 | 示例 | 避免 |
|---|---|---|---|
| 首页 | 产品定位、主要能力与入口 | 3D clothing mockups 与 on-model design | 把首页写成所有品类 generator 的重复集合 |
| 3D 分类 | 款型选择与模型比较 | `/mockups/pants` | 仅罗列图片，没有款型与使用差异 |
| 工具 | 完成明确操作任务 | `/tools/polo-shirt-mockup-generator` | 只重复模板式功能和 FAQ，没有真实结果 |
| 模型详情 | 独特资产、可编辑区域、格式与权限 | 具体 drop shoulder 或 jogger 模型 | 同一段 generic 说明、内部编号作为用户标题 |
| On-model 集合 | 从人物、服装款型与视角选择素材 | `/white-mockups` | 全部筛选参数各自索引、名称混淆纯白背景与人物服装 |
| 教程 | 解决操作与判断问题 | UV、logo placement、360 export | 只追求被 AI 摘抄，缺少可执行例子 |
| AI 能力入口 | 清晰能力、成本、结果和限制 | 待建立公开 AI on-model 说明 | 把工作区 noindex 改掉即视为获客建设完成 |

内链按用户下一步组织：指南 → 对应工具 → 真实资产 → 操作与结果；工具 → 相关操作指南；资产 → 同款型集合。避免所有文章都以完全相同的锚文本只链接首页。

## 不建议立即承诺承接的需求

| 词群 | 问题 | 可以采取的方式 |
|---|---|---|
| `sewing pattern generator`、`pattern drafting software` | 纸样与制版能力未验证 | 清楚说明视觉 mockup 与纸样的区别，不做虚假工具入口 |
| `CLO3D alternative`、`Marvelous Designer alternative` | 专业仿真、制版和格式需求范围更大 | 仅在逐项功能核验后做诚实对比，不泛称替代 |
| `virtual fitting room`、`accurate size try on` | 尺码、人体和合身准确性未验证 | 聚焦 visual preview，避免尺码准确性承诺 |
| `free commercial use clothing models`、`free GLB download` | 免费权限和授权可能不符 | 检查实际许可与 Pro 导出条件后决定是否覆盖 |
| `mockup API`、`automatic Shopify mockups` | 自动化和集成能力未验证 | 若业务决定开发，先作为新能力需求，不先发布虚假 SEO 页面 |
| `Gildan 5000 mockup`、`Bella Canvas 3001 mockup`、`Comfort Colors mockup` | 特定 blank 的真实版型和授权依据未验证 | 有真实对应资产后再纳入，不能用相似模型冒充 |
| `mockup PSD download` | 浏览器输出不等于分层 PSD | 明确当前格式，保留用户正确预期 |
| `dress making game`、`Roblox pants template` | 使用目的不匹配 | 不为获得点击牺牲产品匹配度 |

## 关键词验证与发布条件

对没有 A 级信号的词，按英语美国目标市场做 Google 和 Bing SERP 检查：记录工具、资产市场、教程、实体商店、游戏等结果类型，再核对用户期待的输入与输出。本次公开搜索核实了 on-model、polo branding、boxy/cropped T-shirt、360 与 cap 的竞品入口；其他候选需要继续验证，不能把 80 词都称作已有市场量证明。

第一批只挑 3 至 5 个意图，先完成每组的代表资产与结果图。具备独特内容、真实操作、清楚付费边界后再发布；新工具页和新增交互按项目 AGENTS.md 先生成完整设计稿。仅有关键词没有素材或能力时，不发布空壳页。

发布后用一致 28 天窗口核对发现、收录、曝光、点击、编辑激活、成功导出和首次购买。GA4 测量尚未修复前，以搜索曝光、点击和真实业务记录辅助判断，不能凭当前零收入把某组关键词判定无价值。
